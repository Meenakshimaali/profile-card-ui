# Profile Card UI/UX Design

A profile card UI design created using HTML and CSS.

## Features

- Profile card layout
- Profile image section
- Social media icons
- Subscribe and Message buttons
- Like, comment, and share statistics
- Responsive flexbox-based layout

## Technologies Used

- HTML5
- CSS3
- Font Awesome

## Project Preview

A simple and modern profile card interface designed to practice HTML, CSS, Flexbox, and icon integration.
